# LASER STUDIO PRO

نظام إدارة لمشروع تصميم وقص الليزر، بواجهة Flutter عربية RTL وواجهة داكنة ذهبية.

## الوحدات الموجودة حالياً
- لوحة متابعة الطلبات والمواعيد والمبالغ المستحقة.
- الطلبات والزبائن وسجل دفعات الزبائن.
- المنتجات والأسعار.
- المواد والمخزون وتكلفة الوحدة وحركات الاستهلاك.
- الموردون وفواتير الشراء وسجل الدفعات الجزئية والرصيد المستحق.
- المصاريف التشغيلية والتقارير والحسابات.
- حفظ محلي مع مزامنة حسابية عبر Supabase عند توفر الاتصال، مع معالجة تعارضات الإصدارات.

## الحالة
المشروع قيد التطوير والاختبار. نجاح تحليل Dart وبناء APK لا يعني أن كل مسارات العمل قد اختُبرت ميدانياً أو أن التطبيق إصدار إنتاج نهائي. اختبره أولاً ببيانات تجريبية، ولا تعتمد عليه كسجل وحيد قبل التحقق من المزامنة والنسخ الاحتياطي وسيناريوهات الاستعادة.

## بناء Android
يوجد مسار GitHub Actions لإنتاج APK تجريبي، ومسار منفصل لإنتاج APK إصدار ARM64 للاختبار على أجهزة Android ذات معمارية 64-bit.
- افتح تبويب Actions في GitHub.
- اختر تشغيل البناء الناجح المناسب.
- نزّل ملف Artifact وفك ضغطه.
- ثبّت APK على جهاز Android بعد السماح بالتثبيت من المصدر الذي نزّلت منه.

## ملاحظات البيانات والمزامنة
- البيانات المحلية تبقى محفوظة على الجهاز عند انقطاع الإنترنت، وتُرسل التغييرات المعلّقة عند عودة الاتصال.
- المزامنة تتطلب تسجيل الدخول واتصال Supabase صالحاً.
- استخدم الحساب نفسه على الأجهزة التي تريد مزامنتها.
- لا تحذف بيانات التطبيق أو تسجّل الخروج من جهاز قبل التأكد من ظهور آخر حالة مزامنة ناجحة.
- احتفظ بنسخة احتياطية مستقلة من بيانات العمل المهمة.
