# Laser Pro Studio — Flutter (Windows + Android)

مشروع Laser Pro Studio الخاص. نفس الكود يستهدف Windows وAndroid.

## الحالة الحالية
**إصدار تجريبي غير نهائي.**
- الكود الموجود في `lib/main.dart` يوفّر أساس الطلبات والمخزون وحساب المواد والكهرباء والأرباح والحفظ المحلي.
- لا توجد مزامنة بين الجهازين في هذه النسخة.
- لا تستخدمه كسجل وحيد لطلبات حقيقية حتى تُبنى المزامنة والنسخ الاحتياطي وتُختبر.
- ميزات منتجاتي، الأرشيف المستقل، الزبائن/واتساب، الثيمات الأربعة، مكتبة SVG والتحديث الذاتي ما زالت ضمن مواصفات التطوير وليست جاهزة في هذا الكود.

## تنزيل APK تجريبي من هاتف Android
1. افتح تبويب **Actions** في مستودع GitHub.
2. اختر **Android APK (test build)**.
3. افتح أحدث تشغيل ناجح بعلامة خضراء.
4. من أسفل الصفحة عند **Artifacts** نزّل **Laser-Pro-Studio-Android-TEST**.
5. فك ملف ZIP الذي نزل من GitHub؛ ستجد **app-debug.apk** وثبّته على جهازك إذا كنت موافقاً على تجربة نسخة غير نهائية.
6. سجل البيانات التجريبية فقط؛ البيانات حالياً محفوظة محلياً على هذا الجهاز وليست متزامنة.

إذا كانت العلامة حمراء، لا يمكن تنزيل APK ناجح قبل إصلاح خطأ البناء.

## البناء محلياً على Windows
```bash
flutter create --project-name laser_pro_studio --platforms=windows,android .
flutter pub get
flutter run -d windows
```

## الهدف النهائي المعتمد
مشروع Flutter واحد وواجهتان لـ Windows وAndroid؛ قاعدة بيانات موحّدة ومزامنة اتجاهين مع العمل دون اتصال، ثيمات متنوعة بصرياً، المنتجات والزبائن والطلبات ومواد المخزون والحسابات وملفات SVG، «مشترياتي السابقة» المعزولة، وتحديثات سهلة وحماية البيانات.

**تنبيه:** إنشاء مستودع GitHub وتشغيل بناء APK لا يفعّلان المزامنة تلقائياً. تحتاج المزامنة إلى خدمة قاعدة بيانات واتصال وحساب مستخدم وتنفيذ واختبار منفصلين.
